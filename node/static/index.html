Edits properties.environment, including climate zone, surface cover classification, roughness, topography/bathymetry, and paired population/perimeter values.

ObservationSeries 0
Observing configurations 0

WMDR2 v0.3.x no longer has facility-level deployments. The dated observing context is edited here from ObservationSeries observingConfigurations, including time interval, location context, serial number, and optional instrument references.

Procedures and schedules 0

ObservingProcedures and ReportingProcedures live under each ObservationSeries. They reference reusable schedule objects from properties.schedules.

Reusable schedules 0

Schedules use JSCalendar-like event objects with uid, start, duration, and optional WMO sampling/aggregation extensions.

Instruments 0

Instruments hold catalogue-like information such as manufacturer, model, and observing-method capability. ObservingConfigurations point to instruments when the instrument type is known.
